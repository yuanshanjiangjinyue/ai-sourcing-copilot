# 验收与下一版

当前仓库为公开演示，样例 SKU、厂商、价格均为虚构。静态 Demo 可独立使用。FastAPI 演示接口不接大模型，不连接实时报价与真实供应商。

## P0 验收
- 自然语言需求可以解析成可编辑参数
- 商品匹配必须先执行硬约束过滤
- 兼容证据不足必须标记待核实，不得自动视为合格
- 明确冲突应返回零合格产品
- RFQ 只保存草稿，必须人工审核

## 下一阶段
- 获取授权的真实产品目录及源规格书
- 建立参数事实来源、版本、时间戳
- 引入 Postgres/pgvector 混合召回，但保留确定性约束校验
- 身份鉴权、权限隔离、审计、速率限制、滥用保护
- 使用实际采购买家任务评估正确率、召回率与询价转化

不得以本示例作为生产系统或宣称供应商已报价。
