◈

现在可运行的 Demo

HTML / CSS / 原生 JavaScript；Python FastAPI；SQLite；样例 JSON 目录；规则匹配；RFQ 草稿 API。可本地启动，不需要 API Key。

◇

正式试点的技术栈

Next.js / TypeScript；FastAPI / Pydantic；PostgreSQL + pgvector；对象存储；AI 模型结构化抽取；服务端可配置的兼容性规则；人工审核和审计日志。

接口演示

FastAPI 可用
POST /api/parse { "text": "Linux ARM64 USB3 全局快门 ≥2MP ≥120fps ..." } POST /api/match { "interface": "USB3", "os": "Linux", "arch": "arm64", "min_mp": 2, "min_fps": 120, "max_price": 320 } POST /api/rfqs { "sku": "DEMO-CAM-001", "qty": 20, "destination": "Germany", "requirements": { ... } } GET /api/products GET /api/rfqs GET /docs # 本地 FastAPI 启动时才可用

生产环境需要增加认证、用户隔离、细粒度权限、限流、供应商数据权限、隐私合规、人工报价审核与支付安全。示例 API 不可直接公网部署。
